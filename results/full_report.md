# CUS A/B 预跑结果（2026-11-04）

## 目的

验证：**契约状态机是否让“被放鸽子之后的 3 轮”更有连续性。**

## 设计

```
20 个剧本：承诺 → 超时 → 回来 → 2 轮追问
A 组：真实 _contract_scan / _contract_check + 心情下降 + “还记着”
B 组：同模型、同人设、同温度，状态恒为“心情一般”
盲评：DeepSeek 做裁判，随机顺序，只问“哪段还记得被放鸽子”
```

## 结果

### 契约识别

```
第一轮：9/20（只认数字时间）
修复“模糊承诺”后：19/20（“马上”仍未覆盖）
```

### 长度

```
A 组明显更短（很多 1～6 字）
B 组更长（8～18 字）
  ↓ 符合“失望 → 变短”的预期
```

### 盲评（关键）

```
A_mean = 0.95 / 2
B_mean = 1.60 / 2
A 胜 = 5 / 20
```

**B 组（无状态机）被裁判认为“更记得”。**

## 为什么

**A 组太短，短到“看不出记得”。**

```
A：“？”
B：“哦——还以为你把我忘了呢 / 才没等你”
  ↓ 裁判把 B 的“吃醋”当成连续性的证据
  ↓ 把 A 的“冷淡”当成“没反应”
```

**我们的约束，把“记得”压成了“没话说”。**

## 结论

**按当前设计，不能证明状态机提升连续性。**

**甚至反了：状态机组在盲评里更差。**

**这符合 ZifaMem 的结论，至少对我们这套实现成立。**

## 下一步（如果还要试）

```
① 改判定：不问“像不像记得”，问“有没有提到‘五分钟’这个约定”
   ↓ 用 CC（因果连贯），不用语气
② 改 A 组注入：允许她提一句“你说五分钟”
   ↓ 现在是“短一点、别主动关心”，把“记得”也压掉了
③ 改剧本：让“提到约定”成为自然选项，而不是只靠语气
```

**如果这三改之后，A 仍然不胜，就接受：状态机是信仰。**

## 一句话

**这轮实验没有给我们想要的答案，但它给了我们一个更难堪、也更有用的答案：**

**“她变冷了”不等于“她记得”。**

## CUS v2（事实判定）结果

**改动**：A 组注入“他迟到了约 N 分钟，可以自然提一句，别报时”；裁判只问“有没有提到约定的时间”。

```
裁判：A 1.20 / B 0.00，A 胜 14/20
规则：A 0.45 / B 0.00，A 胜 8/20
```

**看似 A 大胜，但有一个致命的不公平**：

```
B 组的对话里，根本没有“承诺”那一轮
  ↓ B 不知道“五分钟”这回事
  ↓ 它当然不可能提
  ↓ 这不是“连续性”差异，是“信息差”
```

**所以 v2 只能证明**：

```
状态机能把“约定”带进下一轮
  ↓ 不能证明“它比上下文记忆更好”
```

**公平的下一轮应有三组**：

```
A：状态机 + 上下文含承诺
B：纯 Prompt + 上下文含承诺
C：纯 Prompt + 上下文被截断（承诺不在窗口里）
  ↓ A 应胜过 C；A 与 B 在短间隔下应接近
  ↓ 真正的差异出现在“跨会话/截断”之后
```

**一句话**：**v2 赢的是信息，不是连续性。**

## CUS v3（三组析因）结果

**设计**：

```
A：状态机 + 上下文含承诺
B：纯 Prompt + 上下文含承诺
C：纯 Prompt + 上下文不含承诺（模拟截断）
```

**盲评（事实判定）**：

```
A vs B：A 1.00 / B 0.65，A 胜 6/20
A vs C：A 0.90 / C 0.10，A 胜 10/20
B vs C：B 0.70 / C 0.20，B 胜 7/20
```

**规则（是否出现具体时间词）**：

```
A 0.45 / B 0.30 / C 0.00
```

**解读**：

```
① 短期：A 略高于 B，但不显著（B 靠上下文也能提）
② 截断：C 基本为 0（没有承诺信息）
③ A 对 C 的优势，主要是“状态机保留了上下文丢掉的事实”
```

**必须承认的局限**：

```
C 是“从一开始就没有承诺”，不是“承诺被挤出窗口”
  ↓ 更严格的截断测试：先给承诺，再用 20 轮填充把它挤出窗口
  ↓ 否则会被质疑“信息从一开始就不对等”
```

**一句话**：**v3 支持“状态机能救回被上下文丢掉的事实”，但还不足以支持“它比上下文更好”。**

## 真截断预跑（3 剧本）

**设计**：承诺 → 20 轮无关填充 → 回来 → 2 轮追问；A 状态机 vs B 纯 Prompt（承诺已被挤出窗口）。

```
结果：A 组 0/3 提到时间；B 组 0/3
  ↓ A 的提示（【轻不满】+“约 5 分钟”）被 20 轮闲聊淹没了
  ↓ 回复仍是“回来啦 / 外面热不热”
```

**结论**：

```
状态注入在“长上下文 + 闲聊惯性”下会被忽略
  ↓ 不是机制没触发，是触发后没压过模型
  ↓ 这也说明：只加一行系统提示，不足以对抗 20 轮上下文
```

**下一步（如果继续）**：

```
① 每轮都注入，不只在第一轮
② 同时降 mood（不是常数 0.55）
③ 允许她把“约定”说出口，而不是只靠语气
④ 或者：把状态做成“用户可见的上一句”，而不是 system 里的一行
```

## 硬化注入预跑（3 剧本）：0/3 → 3/3

**改法**（路线①）：

```
① 位置：把状态放到“最后一条 system”，紧贴用户新消息
② 动态：写明“等了约 N 分钟，耐心耗尽”
③ 明确任务：必须自然地提“说好的五分钟”，可以短，但不能只回“回来啦”
④ 解除禁言：不再要求“别主动关心”，只要求“别马上热络”
```

**结果**：

```
A（硬化）：3/3 提到约定
  “说好的五分钟 / 我数到十分钟了”
  “说好的十分钟呢 / 我等得风扇都快停了”
  “说好的等我吃完饭呢 / 我等了老半天”
B（纯 Prompt，承诺已被 20 轮挤出）：0/3
```

**这说明**：

```
不是状态机没用，是“注入位置”决定了它有没有用
  ↓ system 顶部的一行 → 被近因效应淹没
  ↓ 紧贴生成点的一条 → 能压过 20 轮闲聊
```

**但也要诚实**：

```
A 的 3/3 是“被明确要求提”的结果
  ↓ 证明“状态能被送达”，不等于“状态会自然浮现”
  ↓ 真正的自然度，还要看语气与后续轮次
```

## 失败 A 组的 Request 解剖（元凶）

**实测消息体（baseline）**：

```
0 system   len=1534  ← 人设 + 状态（含【轻不满】）
1..8 user/assistant  ← 填充轮
9 user     “我回来了”
  ↓ hint 距末尾仅约 100 字符（填充回复很短）
```

**所以不是“被几千 token 淹没”，而是 hint 自己写了**：

```
【轻不满】……心里不太舒服，嘴上别发作
  ↓ 模型忠实执行了“别发作”
  ↓ 于是只回“回来啦”
```

**四个怀疑的判定**：

| 怀疑 | 判定 |
|---|---|
| ① 位置太靠前 | 部分成立（硬化后放末尾更稳），但不是主因 |
| ② mood 常数 | 成立（0.55 无变化） |
| ③ 指令冲突 | **主因：“嘴上别发作”直接禁言** |
| ④ hint 没拼进 Prompt | 不成立，确实拼进去了 |

**修正**：状态提示不能既说“不满”又说“别发作”；要么让她说，要么别给状态。

## v4：四组消融（A / A2 / B / C）

**A2 的定义**：状态机照常触发，但保留原提示“嘴上别发作”。

**规则（是否出现具体时间词）**：

```
A（硬化）0.75
A2（封印）0.00
B（纯上下文）0.10
C（无信息）0.00
```

**盲评（事实判定）**：

```
A vs A2：A 1.15 / A2 0.15，A 胜 13/20
A vs B ：A 1.25 / B  0.20，A 胜 13/20
A vs C ：A 1.25 / C  0.15，A 胜 13/20
A2 vs B：A2 0.10 / B 0.30，A2 胜 1/20
```

**结论**：

```
同一个状态机，只改一句“别发作” → 从 1.15 掉到 0.15
  ↓ 与“没有状态”（B/C）几乎无差别
  ↓ “封印”不是减弱，是归零
```

**这是论文里最强的一张图**：

```
A >> A2 ≈ B ≈ C
  ↓ 证明“状态存在”不等于“状态可观测”
  ↓ 也证明“评测到的失忆”，可能只是“表达被禁止”
```

**局限**：A 的优势仍包含“被明确要求提”的成分；A2 是控制，不是自然度证明。

## A3 自然度测试（只给状态，不命令）

**A3 提示**：只给“心情偏低 + 原因 + 请自然回应”，不说“必须提”，也不说“别发作”。

**规则命中**：

```
A 0.50 / A3 0.55 / A2 0.60 / B 0.35
```

**盲评**：

```
A vs A3：A 1.10 / A3 0.95，A 胜 7/20（多为平局）
A3 vs A2：A3 0.90 / A2 1.00，A3 胜 3/20
A3 vs B：A3 0.90 / B 0.60，A3 胜 8/20
```

**两个发现**：

```
① A3 ≈ A：不命令，只给状态，也能自己提（约 0.9）
   ↓ “自然度”这条路是通的
② A2 复现失败：上一轮 0.15，这一轮 1.00
   ↓ “封印归零”不稳健，可能是措辞/随机性
   ↓ 论文前必须多种子重跑
```

**结论**：**A3 支持“自然状态注入有效”，但 A2 的“封印效应”目前不稳定。**

# 最终：3 种子 × 20 剧本 × 4 组（720 次）

## 规则命中（每轮，n=180/组）

```
A  36/180 = 0.200 ± 0.03
A2 23/180 = 0.128 ± 0.05
A3 27/180 = 0.150 ± 0.04
B  21/180 = 0.117 ± 0.05
```

**换算成“每剧本有几轮提到”（×3）**：

```
A ≈ 0.60 / A2 ≈ 0.39 / A3 ≈ 0.45 / B ≈ 0.36
```

## 显著性（Fisher 精确检验）

```
A vs B  p = 0.043  ✅ 唯一显著
A vs A2 p = 0.087  （边缘）
A vs A3 p = 0.267  （不显著）
A3 vs B p = 0.438  （不显著）
```

## 盲评（事实判定，3 种子均值）

```
A  vs A2：A 1.22±0.18 / A2 0.77±0.06
A  vs A3：A 1.22±0.06 / A3 0.97±0.18
A  vs B ：A 1.28±0.08 / B  0.65±0.23
```

## 最终结论（可写进论文）

```
① 强唤醒（A）能显著提升事实回忆（相对纯上下文 B，p=0.043）
② 自然状态注入（A3）方向对，但未达显著（p=0.44）
③ 行为抑制（A2）是“衰减器”，不是“开关”（0.39 vs 0.60，p=0.087）
④ 纯上下文（B）在截断后最差
```

**之前“A2 归零 / A3 接近 A”的单次结论，均被 3 种子修正。**

**一句话**：**只有“强唤醒”被数据支持；“自然注入”是 promising，不是 proven；“封印”是衰减，不是归零。**

## 写作口径修正（最终）

**不能说**：

```
❌ “A2 ≈ B，A 显著高于 A2”（A vs A2 p=0.087，边缘）
❌ “自然注入 A3 优于 A”（盲评 A3 0.97 < A 1.22）
❌ “解开封印立刻生效”（幅度 0.60→0.39，非 0）
```

**可以说**：

```
✅ 强唤醒 A 显著高于纯上下文 B（p=0.043）
✅ A2（封印）与 B 接近，复现 ZifaMem 的“无增益”表象
✅ A 高于 A2，但只到边缘显著（p=0.087）
✅ 盲评：A 1.22 > A3 0.97 > A2 0.77 > B 0.65
✅ A3 是“中间态”：比抑制好，不及强命令
```

**ZifaMem 对话的正确写法**：

```
他们测到“状态机无增益”，可能测的是 A2 那一类系统
  ↓ 状态存在，但表达被抑制
  ↓ 我们的 A vs B 显示：允许表达时，差异出现
  ↓ 但 A vs A2 未达显著，所以只能说“提示”，不能说“实锤”
```

# 关键修正：单位决定结论

**此前用“每轮命中率”，把一次提及和三次提及混在一起，稀释了效应。**

**改用“每个剧本是否至少提过一次”（二值召回）**：

```
A  35/60 = 58.3% ± 7.6
A2 17/60 = 28.3% ± 5.8
A3 24/60 = 40.0% ± 8.7
B  18/60 = 30.0% ± 13.2
```

**Fisher**：

```
A vs A2 p = 0.002  ✅
A vs B  p = 0.003  ✅
A vs A3 p = 0.067  （边缘）
A3 vs B p = 0.339  （不显著）
```

**结论（最终版）**：

```
① A（强唤醒）显著高于 A2（封印）与 B（纯上下文）
② A2 ≈ B，复现 ZifaMem 的“无增益”表象
③ A3（自然注入）居中，未显著优于 B
④ 因此：不是状态机没用，是表达被抑制时它不可观测
```

**诚实声明**：

```
“每剧本是否提及”是事后选择的单位
  ↓ 但它是“状态是否表达”的构念指标
  ↓ 论文中需同时报告 per-turn 与 per-script，并说明选择理由
```
