# Contrast plan (before Test 2)

> A vs A2 is not a pure permission test: A carries an explicit "you must mention it" command, A2 carries "do not act up". The clean permission contrast is A3 vs A2 (both have state, neither commands).

## Four contrasts

| Contrast | What it actually tests | Dev result (L123, script-level) | Role | n for 80% power |
|---|---|---|---|---|
| **A vs A2** | generation-point command + permission | zh 21/25 vs 11/25, p=.0072; en 24/25 vs 17/25, p=.0232 | command effect; runnable | 50/language |
| **A3 vs A2** | permission only (both no command) | zh 16/25 vs 11/25, p=.256; en 21/25 vs 17/25, p=.321 | mechanism; underpowered at 25 | ~100/language |
| **A2 vs C** | inhibition vs true absence | not run (C new) | mechanism zero point | ~100/language |
| **A vs B** | state vs fact-only reference | zh 21/25 vs 8/25, p=.0004; en 24/25 vs 13/25, p=.0008 | not a no-memory test (B has fact) | reference only |

B is fact-present; A2 vs B is not "muted = absent" (zh p=.56, en p=.39). C is the true absence baseline.

## Two routes

### Route A: command claim (runnable now)

```
Primary: A vs A2 (generation-point instruction)
Secondary/exploratory: A3 vs A2, A2 vs C
Sample: 50 scripts/language
Claim: explicit generation-point instruction drives expression;
       persona inhibition alone is not statistically supported at n=25.
Title must change: not "muted memory" as the main finding.
```

### Route B: suppression claim (scientifically stronger)

```
Primary: A3 vs A2 (permission only)
Secondary: A2 vs C
Sample: ~100 scripts/language (power ~0.8 for .64 vs .44)
Cost: ~2000 calls, ~20 CNY; time in script sourcing/annotation
Claim: inhibition alone lowers expression (if significant).
```

## Do not mix

```
Route A sample size + Route B conclusion = the original problem again.
```

## Probe rules

```
B/C probe ("他答应你几分钟？") is recorded but excluded from scoring.
C must have hint="" and no fact; same late_sec and follow-ups as A/A2/A3.
```

## Recommendation

Run **Route A** for Test 2 now; keep A3 vs A2 and A2 vs C as pre-registered exploratory. If the suppression claim is the goal, plan a second study with 100 scripts/language after this one.
